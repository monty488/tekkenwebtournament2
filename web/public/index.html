    Controls

    Gamepad: standard Xbox layout (X = 1, Y = 2, A = 3, B = 4, RB = Tag).
    Keyboard: WASD/arrows move, U = 1, I = 2, J = 3, K = 4, O = Tag, Enter = Start.
